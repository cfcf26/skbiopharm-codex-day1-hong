
## SK바이오팜 Codex + GitHub 1일차 실습 자료

업무별 엑셀 데이터를 분석하고, 예산 집행 현황을 웹 대시보드로 확인하는 실습 자료입니다. 엑셀의 값과 업무상 주요 명칭은 교육용 가상 데이터입니다.

| 파일 | 용도 |
| --- | --- |
| 과제_마일스톤.xlsx | R&D·임상·허가 과제의 마일스톤 관리 |
| 예산집행.xlsx | 재무·회계·IR 예산 집행 분석 및 대시보드 입력 |
| 파트너링_딜.xlsx | 사업개발·전략 파트너링 딜 관리 |
| 재고_출하.xlsx | SCM·생산 재고 및 출하 관리 |
| 계약대장.xlsx | 경영지원 계약 현황 관리 |

`예산집행-대시보드.html`을 브라우저에서 열면 예산 집행 현황을 확인할 수 있습니다. 파일이 자동으로 열리지 않으면 **엑셀 파일 열기**에서 `예산집행.xlsx`를 선택하세요. `lib/`에는 브라우저에서 엑셀을 읽는 SheetJS 라이브러리와 라이선스가 들어 있습니다. `AGENTS.md`에는 이 저장소의 Git 작업과 커밋 메시지 규칙이 담겨 있습니다.

작성 부서: 재무기획
